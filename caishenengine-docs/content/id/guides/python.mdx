# Integrasi Python

Contoh integrasi menggunakan library `requests` di Python.

## Contoh Kode

<CodeBlock language="python" filename="caishenengine.py">
{`import requests
import os

def create_qris(order_id, amount):
    url = "https://sandbox.caishenengine.com/api/v1/transactions"
    headers = {
        "X-API-Key": os.getenv("caishenengine_API_KEY"),
        "X-Idempotency-Key": order_id,
        "Content-Type": "application/json"
    }
    payload = {
        "amount": amount,
        "currency": "IDR",
        "payment_channel": "qris"
    }
    
    response = requests.post(url, json=payload, headers=headers)
    return response.json()`}
</CodeBlock>
