# Go Live ke Production

Setelah pengujian di sandbox selesai, ikuti checklist berikut untuk mulai menerima pembayaran asli.

## Checklist Go Live

- [ ] Pastikan akun merchant sudah diapprove untuk Production.
- [ ] Ganti Base URL ke `https://api.caishenengine.com`.
- [ ] Ganti API Key ke `caishenengine_live_...`.
- [ ] Pastikan Webhook URL sudah menggunakan HTTPS.
- [ ] Lakukan transaksi riil nominal kecil (misal Rp 1.000) untuk verifikasi akhir.
