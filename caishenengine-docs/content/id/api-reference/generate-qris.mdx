# Generate QRIS

Endpoint ini menerima request generate QRIS, 
merouting ke vendor optimal, dan mengembalikan 
QRIS code yang siap ditampilkan ke user.

<ApiEndpoint method="POST" endpoint="/api/v1/transactions" />

## Request Headers

| Header | Required | Deskripsi |
|--------|----------|-----------|
| `X-API-Key` | ✅ | API key sandbox atau production |
| `Content-Type` | ✅ | `application/json` |
| `X-Idempotency-Key` | ✅ | UUID unik per request |

## Request Body

<ParamTable params={[
  {
    name: "amount",
    type: "integer",
    required: true,
    description: "Nominal transaksi dalam IDR. Satuan rupiah penuh, bukan sen.",
  },
  {
    name: "currency",
    type: "string",
    required: false,
    description: "Mata uang. Saat ini hanya IDR yang didukung.",
    default: "IDR",
    enum: ["IDR"]
  },
  {
    name: "payment_channel",
    type: "string",
    required: false,
    description: "Channel pembayaran.",
    default: "qris",
    enum: ["qris"]
  }
]} />

## Response

### 200 — Success

```json
{
  "transaction_id": "caishenengine_20260510_a1b2c3d4e5f6",
  "status": "pending_payment",
  "qris_code": "00020101021226660014ID.CO.QOINHUB...",
  "amount": 50000,
  "currency": "IDR",
  "payment_channel": "qris",
  "vendor_id": "QOINHUB",
  "environment": "sandbox",
  "expires_at": "2026-05-10T14:47:00Z",
  "created_at": "2026-05-10T14:32:00Z"
}
```

### Error Responses

| HTTP | Error Code | Deskripsi |
|------|------------|-----------|
| 400 | `INVALID_AMOUNT` | Amount kurang dari atau sama dengan 0 |
| 400 | `INVALID_CURRENCY` | Currency selain IDR |
| 409 | `IDEMPOTENCY_CONFLICT` | Idempotency key dipakai ulang dengan parameter berbeda |
| 429 | `RATE_LIMITED` | Melebihi batas TPS |
| 429 | `VOLUME_EXCEEDED` | Melebihi batas volume harian |
| 503 | `NO_ELIGIBLE_VENDOR` | Tidak ada vendor yang tersedia |
| 503 | `VENDOR_ERROR` | Semua vendor gagal |
