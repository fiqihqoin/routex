# List Transaksi

Endpoint ini mengembalikan daftar transaksi terbaru dalam akun Anda.

<ApiEndpoint method="GET" endpoint="/api/v1/transactions" />

## Query Parameters

| Parameter | Type | Required | Default | Deskripsi |
|-----------|------|----------|---------|-----------|
| `limit` | integer | ❌ | 10 | Jumlah data per halaman |
| `page` | integer | ❌ | 1 | Halaman ke-berapa |
| `status` | string | ❌ | - | Filter berdasarkan status |

## Response

### 200 — Success

```json
{
  "data": [
    {
      "transaction_id": "caishenengine_20260510_a1b2c3d4",
      "status": "settled",
      "amount": 50000,
      "created_at": "2026-05-10T14:32:00Z"
    }
  ],
  "meta": {
    "total": 1,
    "limit": 10,
    "page": 1
  }
}
```
