# Introduction to CaishenEngine

CaishenEngine is a **payment traffic management system** that 
sits between your application and payment gateways. 
CaishenEngine intelligently routes, limits, and protects 
your payment transaction traffic.

<Callout type="info">
CaishenEngine is **not** a payment gateway. CaishenEngine only 
routes requests — it does not process transactions, 
card tokenization, or fund settlements.
</Callout>

## How CaishenEngine Works

The QRIS payment flow through CaishenEngine:

1. **Generate** — Your application calls CaishenEngine API → 
   CaishenEngine selects the optimal vendor → returns the 
   QRIS code.
2. **Pay** — User scans the QRIS via banking/e-wallet app.
3. **Callback** — Vendor notifies CaishenEngine → CaishenEngine 
   forwards the normalized callback to your webhook URL.

## Key Advantages

### Maximize Success Rate
Automated routing avoids problematic vendors in 
real-time through a penalty system and 
circuit breakers.

### Volume Protection
Rate limiting per-account, per-vendor, and per-user 
ensures you don't exceed contractual limits 
with vendors.

### Cost Optimization
Basket-size routing selects vendors based on 
cost efficiency per transaction nominal bracket.

### Full Observability
Every routing decision, vendor health status, and 
transaction state is tracked in real-time.
