# Error Handling

CaishenEngine uses standard HTTP response codes to indicate the success or failure of a request.

## Error Structure

```json
{
  "error": {
    "code": "INVALID_AMOUNT",
    "message": "The amount must be greater than 0"
  }
}
```

## Common Error Codes

| HTTP | Code | Description |
|------|------|-------------|
| 400 | `BAD_REQUEST` | The request was invalid |
| 401 | `UNAUTHORIZED` | Invalid or missing API Key |
| 403 | `FORBIDDEN` | No access to this resource |
| 404 | `NOT_FOUND` | Resource not found |
| 429 | `TOO_MANY_REQUESTS` | Rate limit exceeded |
| 500 | `INTERNAL_SERVER_ERROR` | Internal server error occurred |
