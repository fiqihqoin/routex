# Quick Start

This guide will walk you through generating your first QRIS code 
through CaishenEngine in just 5 minutes.

## Prerequisites

- An active CaishenEngine account 
  ([Register here](https://app.caishenengine.com/register))
- At least one vendor configured in the 
  CaishenEngine portal
- A sandbox API Key (received after account approval)

## Step 1 — Get your API Key

Once your account is approved, you will receive an email 
containing two API keys:

- **Sandbox Key** — starts with `caishenengine_sb_`
- **Production Key** — starts with `caishenengine_live_`

For development, please use the sandbox key first.

<Callout type="warning">
Never expose your API key in client-side code 
or public repositories. Use environment variables.
</Callout>

## Step 2 — Generate QRIS

<ApiEndpoint method="POST" endpoint="/api/v1/transactions" />

Your first request:

```bash
curl -X POST https://sandbox.caishenengine.com/api/v1/transactions \
  -H "Content-Type: application/json" \
  -H "X-API-Key: caishenengine_sb_your_key_here" \
  -H "X-Idempotency-Key: order-12345" \
  -d '{
    "amount": 50000,
    "currency": "IDR",
    "payment_channel": "qris"
  }'
```

Successful response:

```json
{
  "transaction_id": "caishenengine_20260510_a1b2c3d4",
  "status": "pending_payment",
  "qris_code": "00020101021226...",
  "amount": 50000,
  "currency": "IDR",
  "payment_channel": "qris",
  "expires_at": "2026-05-10T14:47:00Z",
  "created_at": "2026-05-10T14:32:00Z"
}
```

## Step 3 — Check Transaction Status

```bash
curl https://sandbox.caishenengine.com/api/v1/transactions/caishenengine_20260510_a1b2c3d4 \
  -H "X-API-Key: caishenengine_sb_your_key_here"
```

## Step 4 — Setup Webhook (Optional)

Register a webhook URL in the [CaishenEngine portal](https://app.caishenengine.com/portal/webhooks) 
to receive notifications when a payment is completed.
