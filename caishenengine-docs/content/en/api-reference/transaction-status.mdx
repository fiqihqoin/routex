# Get Transaction Status

Use this endpoint to manually check the current payment status.

<ApiEndpoint method="GET" endpoint="/api/v1/transactions/{transaction_id}" />

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `transaction_id` | string | ✅ | Transaction ID from CaishenEngine |

## Response

### 200 — Success

```json
{
  "transaction_id": "caishenengine_20260510_a1b2c3d4",
  "status": "settled",
  "amount": 50000,
  "currency": "IDR",
  "payment_channel": "qris",
  "paid_at": "2026-05-10T14:40:00Z",
  "created_at": "2026-05-10T14:32:00Z"
}
```

## Status List

| Status | Description |
|--------|-------------|
| `pending_payment` | QRIS generated, waiting for user payment |
| `settled` | Payment successfully received |
| `expired` | QRIS has expired |
| `failed` | Transaction failed |
| `refunded` | Funds have been returned to the user |
