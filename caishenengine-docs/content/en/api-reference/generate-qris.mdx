# Generate QRIS

This endpoint receives a QRIS generation request, 
routes it to the optimal vendor, and returns a 
QRIS code ready to be displayed to the user.

<ApiEndpoint method="POST" endpoint="/api/v1/transactions" />

## Request Headers

| Header | Required | Description |
|--------|----------|-----------|
| `X-API-Key` | ✅ | Sandbox or production API key |
| `Content-Type` | ✅ | `application/json` |
| `X-Idempotency-Key` | ✅ | Unique UUID per request |

## Request Body

<ParamTable params={[
  {
    name: "amount",
    type: "integer",
    required: true,
    description: "Transaction nominal in IDR. Full rupiah unit, not cents.",
  },
  {
    name: "currency",
    type: "string",
    required: false,
    description: "Currency. Currently only IDR is supported.",
    default: "IDR",
    enum: ["IDR"]
  },
  {
    name: "payment_channel",
    type: "string",
    required: false,
    description: "Payment channel.",
    default: "qris",
    enum: ["qris"]
  }
]} />

## Response

### 200 — Success

```json
{
  "transaction_id": "caishenengine_20260510_a1b2c3d4e5f6",
  "status": "pending_payment",
  "qris_code": "00020101021226660014ID.CO.QOINHUB...",
  "amount": 50000,
  "currency": "IDR",
  "payment_channel": "qris",
  "vendor_id": "QOINHUB",
  "environment": "sandbox",
  "expires_at": "2026-05-10T14:47:00Z",
  "created_at": "2026-05-10T14:32:00Z"
}
```

### Error Responses

| HTTP | Error Code | Description |
|------|------------|-----------|
| 400 | `INVALID_AMOUNT` | Amount is less than or equal to 0 |
| 400 | `INVALID_CURRENCY` | Currency other than IDR |
| 409 | `IDEMPOTENCY_CONFLICT` | Idempotency key reused with different parameters |
| 429 | `RATE_LIMITED` | Exceeded TPS limit |
| 429 | `VOLUME_EXCEEDED` | Exceeded daily volume limit |
| 503 | `NO_ELIGIBLE_VENDOR` | No eligible vendor available |
| 503 | `VENDOR_ERROR` | All vendors failed |
