# Going Live to Production

Once sandbox testing is complete, follow this checklist to start accepting real payments.

## Go Live Checklist

- [ ] Ensure your merchant account is approved for Production.
- [ ] Change Base URL to `https://api.routex.id`.
- [ ] Change API Key to `ptms_live_...`.
- [ ] Ensure Webhook URL is using HTTPS.
- [ ] Perform a small nominal real transaction (e.g., Rp 1,000) for final verification.
