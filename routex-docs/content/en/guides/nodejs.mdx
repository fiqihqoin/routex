# Node.js Integration

Here is a complete example of how to perform a QRIS generation request in Node.js.

## Code Example

<CodeBlock language="javascript" filename="routex.js">
{`const createTransaction = async (orderId, amount) => {
  const response = await fetch('https://sandbox.routex.web.id/api/v1/transactions', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': process.env.ROUTEX_API_KEY,
      'X-Idempotency-Key': orderId
    },
    body: JSON.stringify({
      amount: amount,
      currency: 'IDR',
      payment_channel: 'qris'
    })
  });

  return await response.json();
};`}
</CodeBlock>
