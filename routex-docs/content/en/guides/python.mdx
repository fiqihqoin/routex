# Python Integration

Example of integration using the `requests` library in Python.

## Code Example

<CodeBlock language="python" filename="routex.py">
{`import requests
import os

def create_qris(order_id, amount):
    url = "https://sandbox.routex.id/api/v1/transactions"
    headers = {
        "X-API-Key": os.getenv("ROUTEX_API_KEY"),
        "X-Idempotency-Key": order_id,
        "Content-Type": "application/json"
    }
    payload = {
        "amount": amount,
        "currency": "IDR",
        "payment_channel": "qris"
    }
    
    response = requests.post(url, json=payload, headers=headers)
    return response.json()`}
</CodeBlock>
