# Idempotency

Routex supports idempotency to prevent accidental duplicate transaction creation.

## How to Use

Include the `X-Idempotency-Key` header with a unique UUID value for every transaction request.

```bash
X-Idempotency-Key: your-unique-uuid
```

If Routex receives a second request with the same key within 24 hours, Routex will return the same response without re-processing the transaction.

<Callout type="tip">
Use your system's Order ID as the Idempotency Key to ensure safe synchronization.
</Callout>
