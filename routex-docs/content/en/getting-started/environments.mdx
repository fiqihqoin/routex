# Environments

Routex provides two separate environments to assist your development and integration process.

## Sandbox

The sandbox environment is used for testing without using real funds.

- **Base URL**: `https://sandbox.routex.id`
- **API Key Prefix**: `ptms_sb_`
- **Purpose**: Development, integration testing, callback simulation.

## Production

The production environment is used for real transactions with actual funds.

- **Base URL**: `https://api.routex.id`
- **API Key Prefix**: `ptms_live_`
- **Purpose**: Live business transactions.

<Callout type="warning">
Always ensure you are using the correct API Key matching the base URL you are calling.
</Callout>
