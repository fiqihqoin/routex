# v1.0.0

This is the first stable release of Routex.

## New Features

- **Multi-vendor QRIS**: Support for Qoinhub, Midtrans, and Xendit.
- **Dynamic Routing**: Automatic vendor selection based on success rates.
- **Smart Rate Limiting**: Transaction limits per vendor and per merchant.
- **Unified Webhooks**: Standard notification format for all vendors.
- **Sandbox Environment**: Full simulation for development.
