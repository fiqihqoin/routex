# Webhook Overview

Webhooks allow CaishenEngine to automatically send notifications to your server whenever a transaction status change occurs (e.g., when a payment is successful).

## Why Use Webhooks?

Without webhooks, your server would have to perform polling (repeatedly calling the status check API) to know if a user has paid. Webhooks eliminate this need by pushing data directly to your system.

## Webhook Flow

1. User completes the QRIS payment.
2. Vendor (e.g., Midtrans) sends a notification to CaishenEngine.
3. CaishenEngine processes the data and normalizes its format.
4. CaishenEngine sends a POST request to your registered Webhook URL.
5. Your server processes the data and responds with 200 OK.
