# Transaction Status

Every transaction in Routex will always have one of the following statuses:

| Status | Description |
|--------|-------------|
| `pending_payment` | Transaction created, waiting for user payment |
| `settled` | Funds successfully received |
| `expired` | Payment time expired |
| `failed` | Failed to process |
| `refunded` | Funds returned to the user |
| `voided` | Transaction cancelled |
