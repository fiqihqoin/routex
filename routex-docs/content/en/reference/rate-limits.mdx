# Rate Limits

To maintain system stability, Routex applies request limits (Rate Limiting).

## General Limits

| Account Type | TPS (Transactions Per Second) |
|--------------|-------------------------------|
| Sandbox | 2 TPS |
| Production (Standard) | 10 TPS |
| Production (Enterprise) | Custom |

<Callout type="warning">
Requests exceeding the limit will receive a `429 Too Many Requests` status.
</Callout>
