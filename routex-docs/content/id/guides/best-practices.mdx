# Best Practices

Ikuti panduan ini untuk memastikan integrasi Anda berjalan optimal.

## Keamanan

1. **Gunakan Environment Variables**: Jangan hardcode API Key.
2. **Gunakan HTTPS**: Wajib untuk Webhook URL.
3. **Verifikasi Signature**: Selalu cek HMAC signature pada setiap webhook yang diterima.

## Performa

1. **Handle Timeout**: Set timeout request minimal 30 detik.
2. **Implementasikan Retry**: Gunakan exponential backoff jika request ke CaishenEngine gagal (status 5xx).
3. **Gunakan Idempotency**: Selalu kirim `X-Idempotency-Key` untuk menghindari double charging.
