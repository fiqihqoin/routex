# Testing di Sandbox

Sebelum Go Live, Anda wajib melakukan pengujian menyeluruh di sandbox.

## Cara Simulasi Pembayaran

Karena sandbox tidak menggunakan uang asli, Anda bisa mensimulasikan status pembayaran melalui portal.

1. Generate QRIS di sandbox.
2. Buka [Sandbox Portal](https://app.routex.web.id/portal/sandbox).
3. Cari transaksi Anda dan klik tombol **Simulate Success**.
4. Periksa apakah sistem Anda menerima webhook dengan benar.
