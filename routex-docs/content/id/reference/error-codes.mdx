# Daftar Error Codes

Berikut adalah referensi lengkap semua error code yang mungkin dikembalikan oleh Routex API.

## Client Errors (4xx)

| Code | Deskripsi |
|------|-----------|
| `MISSING_API_KEY` | Header X-API-Key tidak ditemukan |
| `INVALID_AMOUNT` | Amount harus > 0 |
| `INVALID_CURRENCY` | Hanya IDR yang didukung |
| `IDEMPOTENCY_CONFLICT` | Key sama dengan parameter berbeda |

## Server Errors (5xx)

| Code | Deskripsi |
|------|-----------|
| `VENDOR_UNAVAILABLE` | Vendor sedang down |
| `ROUTING_ERROR` | Gagal menemukan jalur routing |
| `INTERNAL_ERROR` | Terjadi kesalahan sistem |
