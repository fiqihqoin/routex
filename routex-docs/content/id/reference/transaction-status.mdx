# Status Transaksi

Setiap transaksi di Routex akan selalu memiliki salah satu dari status berikut:

| Status | Deskripsi |
|--------|-----------|
| `pending_payment` | Transaksi dibuat, menunggu pembayaran user |
| `settled` | Dana berhasil diterima |
| `expired` | Waktu bayar habis |
| `failed` | Gagal diproses |
| `refunded` | Dana dikembalikan ke user |
| `voided` | Transaksi dibatalkan |
