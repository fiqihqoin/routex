# v1.0.0

Ini adalah rilis stabil pertama CaishenEngine.

## Fitur Baru

- **Multi-vendor QRIS**: Support Qoinhub, Midtrans, dan Xendit.
- **Dynamic Routing**: Pemilihan vendor otomatis berdasarkan success rate.
- **Smart Rate Limiting**: Batasan transaksi per vendor dan per merchant.
- **Unified Webhooks**: Format notifikasi standar untuk semua vendor.
- **Sandbox Environment**: Simulasi penuh untuk pengembangan.
