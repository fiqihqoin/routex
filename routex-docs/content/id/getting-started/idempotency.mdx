# Idempotency

Routex mendukung idempotensi untuk mencegah pembuatan transaksi ganda secara tidak sengaja.

## Cara Menggunakan

Sertakan header `X-Idempotency-Key` dengan nilai UUID yang unik untuk setiap transaksi.

```bash
X-Idempotency-Key: your-unique-uuid
```

Jika Routex menerima request kedua dengan key yang sama dalam waktu 24 jam, Routex akan mengembalikan response yang sama tanpa memproses transaksi ulang.

<Callout type="tip">
Gunakan Order ID dari sistem Anda sebagai Idempotency Key untuk memastikan sinkronisasi yang aman.
</Callout>
