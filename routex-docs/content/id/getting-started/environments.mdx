# Environments

Routex menyediakan dua environment terpisah untuk membantu proses pengembangan dan integrasi Anda.

## Sandbox

Environment sandbox digunakan untuk pengujian tanpa menggunakan dana riil.

- **Base URL**: `https://sandbox.routex.web.id`
- **API Key Prefix**: `ptms_sb_`
- **Tujuan**: Pengembangan, pengujian integrasi, simulasi callback.

## Production

Environment production digunakan untuk transaksi riil dengan dana sesungguhnya.

- **Base URL**: `https://api.routex.web.id`
- **API Key Prefix**: `ptms_live_`
- **Tujuan**: Transaksi bisnis live.

<Callout type="warning">
Selalu pastikan Anda menggunakan API Key yang sesuai dengan base URL yang dipanggil.
</Callout>
