# Pengenalan Routex

Routex adalah **payment traffic management system** yang 
berada di antara aplikasimu dan payment gateway. 
Routex secara cerdas merouting, membatasi, dan 
melindungi traffic transaksi pembayaran.

<Callout type="info">
Routex **bukan** payment gateway. Routex hanya 
merouting request — tidak memproses transaksi, 
tokenisasi kartu, atau settlement dana.
</Callout>

## Cara Kerja Routex

Alur pembayaran QRIS melalui Routex:

1. **Generate** — Aplikasimu call Routex API → 
   Routex memilih vendor optimal → mengembalikan 
   QRIS code
2. **Bayar** — User scan QRIS via banking/e-wallet app
3. **Callback** — Vendor notifikasi Routex → Routex 
   forward callback yang sudah dinormalisasi ke 
   webhook URL kamu

## Keunggulan Routex

### Maksimalkan Success Rate
Routing otomatis menghindari vendor yang bermasalah 
secara real-time melalui sistem penalty dan 
circuit breaker.

### Proteksi Volume
Rate limiting per-account, per-vendor, dan per-user 
memastikan kamu tidak melebihi batas kontraktual 
dengan vendor.

### Optimasi Biaya
Basket-size routing memilih vendor berdasarkan 
efisiensi biaya per bracket nominal transaksi.

### Observabilitas Penuh
Setiap keputusan routing, kesehatan vendor, dan 
status transaksi terlacak secara real-time.
