# Setup Webhook

Ikuti langkah berikut untuk mulai menerima notifikasi CaishenEngine.

## 1. Siapkan Endpoint di Server Anda

Buat endpoint yang menerima request `POST` dengan body JSON.

## 2. Daftarkan URL di Portal

Buka [Dashboard CaishenEngine → Settings → Webhooks](https://app.routex.web.id/portal/webhooks) dan masukkan URL server Anda.

## 3. Verifikasi Endpoint

CaishenEngine akan mengirimkan test ping saat Anda menyimpan URL. Pastikan server Anda mengembalikan status `200 OK`.

<Callout type="warning">
Selalu gunakan HTTPS untuk endpoint webhook Anda guna menjaga keamanan data transaksi.
</Callout>
