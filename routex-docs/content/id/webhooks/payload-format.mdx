# Format Payload

Routex menormalkan data dari berbagai vendor ke dalam satu format standar agar integrasi Anda tetap konsisten.

## Contoh Payload Sukses

```json
{
  "event": "transaction.settled",
  "data": {
    "transaction_id": "ptms_20260510_a1b2c3d4",
    "status": "settled",
    "amount": 50000,
    "currency": "IDR",
    "payment_channel": "qris",
    "paid_at": "2026-05-10T14:40:00Z"
  }
}
```

## Daftar Event

| Event | Deskripsi |
|-------|-----------|
| `transaction.settled` | Pembayaran berhasil diterima |
| `transaction.failed` | Transaksi gagal di sisi vendor |
| `transaction.expired` | QRIS sudah tidak bisa dibayar |
